# Legacy Shiny implementation (reference only)

This directory contains the historical R/Shiny implementation of
AnnotateR. It has been fully superseded by the current Python/Streamlit
product and is **not** part of the product or the production Docker image
(see `.dockerignore` and `Dockerfile`).

**Historical license headers:** the files here retain their original
author-header license statements (e.g. "License: GNU GPLv3" in
`app/app.R`, "GNU3 open license" in `app/annotater.R`) unchanged, as part
of the historical record. They do not describe the current product:
**the current AnnotateR Python/Streamlit release is licensed under
BSD-3-Clause** (see the root `LICENSE` file). No claim is made about
retroactive relicensing of the historical implementation.

The files are retained temporarily for historical/reference purposes
pending a post-acceptance cleanup decision. See
[docs/legacy.md](../docs/legacy.md) for the full inventory and
disposition.
